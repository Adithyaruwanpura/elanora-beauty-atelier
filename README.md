# Élanora — Beauty Atelier

Élanora is a premium multi-page beauty and salon website created as a frontend and UI/UX practical assessment.

The project explores a contemporary editorial approach to beauty culture through refined typography, asymmetric layouts, responsive interactions and subtle motion.

## Pages

- Home
- Services
- Experience
- Gallery
- Interactive Appointment Booking

## Features

- Premium editorial UI/UX
- Fully responsive layouts
- Interactive multi-step booking experience
- Smooth page and scroll animations
- Micro-interactions and hover states
- Responsive mobile navigation
- Reusable React components
- Optimized Next.js images
- Accessibility considerations
- SEO metadata
- Production-ready build

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Motion
- Lucide React

## Design Direction

Élanora combines contemporary beauty culture with an understated luxury aesthetic. The visual system uses warm neutral tones, expressive serif typography, generous whitespace and editorial imagery.

The interface was designed to feel closer to a premium beauty publication or fashion house than a conventional salon website.
